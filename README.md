# Mathematical Curves and Geometric Visualizations

This repository contains a comprehensive collection of 20 Python scripts dedicated to simulating, rendering, and analyzing mathematical curves, coordinate transformations, and differential trajectories. It spans classic conic sections, mechanical kinematic paths, transcendental spirals, and spatial manifolds.

The scripts utilize `numpy` for efficient array operations and `matplotlib` (including 3D projection engines) to generate high-quality, publication-ready vector plots with strict geometric aspect ratios.

## Repository Structure & Classification

The 20 scripts are organized into logical groups based on their algebraic classification, kinematic generation, or geometric transformation principles.

### 1. Conic Sections & Fundamentials (Kuželosečky a základní křivky)
* **Circle_Kruznice.py**: Visualization of circular geometry using both implicit Cartesian grids and parametric trigonometric scripting.
* **Ellipse_Elipsa.py**: Parametric representation of ellipses, mapping major and minor semi-axes.
* **Parabola_Parabola.py**: Quadratic algebraic curves mapping vertex forms and focus-directrix relationships.
* **Hyperbola_Hyperbola.py**: Dual-branched open conic sections modeled via hyperbolic functions.
* **Rotated_conics_Otocena_kuzelosecka.py**: Advanced implementation of conic sections rotated by an arbitrary angle \(\theta\) using coordinate rotation matrices.

### 2. Kinematic, Variational & Cycloid Curves (Kinematické, variační a cyklické křivky)
* **Brachistochrone_tautochrone_Brachistochrona_Tautochrona.py**: Simulation of the curve of fastest descent (Brachistochrone) and equal time of descent (Tautochrone) under uniform gravity.
* **Cycloid_Cykloida.py**: Trajectory generated by a fixed point on the rim of a wheel rolling along a straight line.
* **Cardioid_Kardioida.py**: A heart-shaped curve traced by a point on the perimeter of a circle rolling around a fixed circle of equal radius.
* **Hypocycloid_Hypocykloida.py**: Mathematical paths traced by a point on a circle rolling along the *inside* of a larger fixed circle.
* **Involute_curve_Evolventa.py**: The involute of a circle—the mechanical trajectory of a taut string unwinding from a stationary cylinder.
* **Catenary_Retezovka.py**: The ideal physical curve formed by a flexible chain hanging freely under its own weight (hyperbolic cosine).

### 3. Transcendental, Polar & Complex Spirals (Spirály a polární křivky)
* **Cornu_spiral_Klotoida.py**: The clothoid/Cornu spiral, a curve whose curvature changes linearly with its arc length, evaluated via Fresnel integrals.
* **Cassini_oval_Cassiniho_krivka.py**: Locus of points where the product of distances to two fixed foci is constant.
* **Poinsot_Nielsen_Sici_spiral_Poinsot_Nielsen_Sici_spirala.py**: Advanced transcendental and architectural spirals combining multiple polar coordinate definitions.
* **Spirals_all_in_one_Spiraly_vse_v_jednom.py**: Unified benchmark script plotting and comparing Archimedean, Logarithmic, and Fermat spirals on a single canvas.
* **Spirals_separated_Spiraly_oddelene.py**: Individual sub-plots detailing discrete properties of different spiral taxonomy families.

### 4. Mathematical Utilities, Transforms & Tangents (Transformace, grafy a tečny)
* **Geometric_transform_Geometricka_transformace.py**: Visual demonstration of matrix transformations (scaling, shearing, rotation, reflection) on planar shapes.
* **Graph_cartesian_polar_Graf_kartezsky_polarne.py**: Comparative engine illustrating how identical functions map differently between Cartesian grids and Polar grids.
* **Tangent_Tecna.py**: Programmatic calculation and visualization of first-derivative tangent lines at any continuous point along a given curve.

### 5. 3D Spatial Systems (Prostorové křivky)
* **Helix_Sroubovice.py**: A 3D spatial curve combining constant planar rotation with uniform vertical translation along the Z-axis.

## Core Technical Implementations

### 1. Vectorized Kinematic Intervals (Involute String Unwinding)
Parametric kinematic curves calculate coupled trigonometric and linear intervals simultaneously over a continuous vector `t`:

```python
# Vectorized computation of a circle involute
x = radius * (np.cos(t) + t * np.sin(t))
y = radius * (np.sin(t) - t * np.cos(t))
```

### 2. Numerical Integration for Clothoids (Cornu Spiral)
For differential transcendental curves, the repository utilizes `scipy.special.fresnel` to instantly map the core integrations without slow, iterative loops:

```python
from scipy.special import fresnel
y_integrated, x_integrated = fresnel(t_array)
```

### 3. Coordinate Rotations via Matrix Multiplication
To render arbitrarily rotated conics, a 2D rotation matrix is vectorized and applied across the state space:

```python
rotation_matrix = np.array([[1,np.sin(p)],
                         [np.cos(p),1]])
rotated_coordinates = rotation_matrix @ original_state_vector
```
